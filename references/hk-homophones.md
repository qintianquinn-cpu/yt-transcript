# 香港场景高频同音错字

Whisper 听写粤语时的错误高度集中在**同音字**和**粤语独有词**。以下按「转写出来 → 应该是 → 说明」整理，前 13 条来自 2023/24 協恩小學讲座的实测，后半部分为同类场景的通用预期。

## 一、实测遇到的

| 转写 | 正确 | 说明 |
|---|---|---|
| 協音 / 協定 / 協議 | **協恩** | 校名 Heep Yunn（協恩）。同一校名在 37 分钟里被听成三种，说明粤语专名必须人工兜底 |
| 修生取錄 | **學生取錄** | 「學」被听成「修」 |
| 女女 | **女兒／小朋友** | 粤语「女女」即女儿 |
| 在一方陽光下 | **在同一屋簷下** | 意译。「同一屋簷下」是自然说法 |
| condom | **comment** | 填表栏位名，英文词被听岔 |
| 粗行 / 初愛為主 / 倉海為主 | **成績／沉了底** | 「沉底」是粤语说法，指被埋在数据里没被发现 |
| 放外活動 / 聯科活動 | **課外活動** | 两处都错 |
| 獎佐學金 | **獎助學金** | |

| 硬來 | **照填** | 意译 |
| 進列 | **盡列** | 成语「难以尽列」 |

## 三、只转字不够，要重写句子

同音字改完，句子往往仍然不是书面语。这类地方直接按上下文重写，并标「意译」：

- 「我都就著申請，我想有少少提醒」→ 「接着我就着申请补充几点」
- 「最後跟大家說謝謝」→ 可保留
- 「我們很強的辯論員，或者是戲劇工作人員，他們都不一定有」→ 语义接不上，属于 ASR 断句错误，需要按上下文补齐或标〔听不清〕

## 四、其他容易错的香港专名

- **机构**：教育局、學生資助處、學生資助處「中小學學生津貼計劃」、校董會
- **学制术语**：學位、學額、統一派位、自主收生、叩門、不受約束分數、直資（直屬撥款）、津校、資助（津貼）校、SSO、TSL、STS
- **表格代号**：表格 A / B / C、表格 D——务必核原始视频里的画面
- **校名**：協恩（Heep Yunn）、聖安多尼（St. Anthony's）、聖保羅（St. Paul's）…… 注意「聖」在粤语读 sing1，whisper 容易听成「神」「升」
- **人名**：粤语人名两个字的字面意思跟实际读音常无关联，一律回到原始转写逐字核，并注意校长/副校长等职务

## 五、核对方法

1. 打开原视频对应时间码，**听原音**确认，不要只靠上下文猜；
2. 机构的官方名称以**官网**为准（搜索一次即可，比反复听音频快）；
3. 数字类（学额数、日期、百分比、金额）必须回到原音核，因为这类错误在文稿里影响最大；
4. 每个修正都记进「订正记录表」：原文 → 改正 → 依据。
